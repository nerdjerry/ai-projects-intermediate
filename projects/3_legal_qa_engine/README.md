# Legal Q&A Engine (Fine-Tuned)

Domain-specialized legal LLM for contract analysis, risk detection, and Q&A.

## Features
- Build datasets from contracts (Q&A + risk labels)
- Clean, chunk, and label clauses
- Fine-tune models (OpenAI / open-source)
- FastAPI endpoints: `/summarize`, `/analyze-risk`, `/ask`
- Streamlit UI for document upload and interaction
